## 体裁

- 指示書に指示のある印字行数（下記）で印字した結果、指定の頁に足らない、又は、頁が増える場合の対処について（17-02-02/661号/二村）

    - 11Q 48字詰、19行（19～21行OK、この行数以外は不可）
    - 13Q 40字詰、18行（18～20行OK、この行数以外は不可）

- 指示された行組と異なる行組「19～21行」でおさめた場合  ->  連絡票記載不要。
- 「21行」でも指示された頁におさまらない場合
    - はみ出した頁の丁数は、指定丁数の最後の **丁数に「↓」を付加し、「ミシンケイ」** を印字して、連絡票に記入。
- 記載例

  ```
  ★	★	指定頁に収まらないため、ミシンケイを印字しました。
  ```

- 「19行」でも指示された頁に足りない場合
    - 「19行」でなりゆき印字し、**「ミシンケイ」** を印字して、連絡票に記入。
- 記載例

  ```
  ★	★	指定頁に満たなかったため、ミシンケイを印字しました。
  ```

- 原稿に「22行」などの「19～21行」以外の行数指示があり、指示された行数で指定頁に納まるときは、**指示された行数で印字** しても構いません。

- **【重要】**（判決理由）の下がりは、直後に項目番号があれば「問答2」。項目番号がなければ「問答1」。
- 項目の字下げは『段々下がり』。
    - 後に出てくる項目の方が字下げが上になることもあるので、**判決理由全体** で判断してください。
